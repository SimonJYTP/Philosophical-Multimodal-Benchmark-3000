# Algorithm

1. Select every HL item that passes the strict or enrichment rule.
2. Retain the deduplicated HSSBench philosophy/ethics subset.
3. Retain all prior MM records and fill each foundation-task stratum from the complete official query set using a stable hash.
4. Stratify the high-quality VULCA L5 text-proxy subset by culture and theme.
5. Hash image bytes, bind duplicate-content groups to a single split, and assign all other records by stable stratified hashing.
6. Emit aligned release artifacts and run quality assertions.
